# Open Problems

This section records unresolved questions rather than forcing premature answers.

## Current set
1. What is consciousness?
2. What is awareness?
3. What is perception before interpretation?
4. What is knowledge?
5. Does consciousness precede knowledge?
6. What is the relation between knowledge and truth?
7. What is wisdom?
8. Is consciousness fundamental or emergent?
9. If every particle is conscious, how do unified subjects arise?
10. Is quantum mechanics relevant to consciousness, and if so, in what defensible sense?
11. Is the subject/object distinction fundamental?
12. What evidence could distinguish metaphysical possibilities?
